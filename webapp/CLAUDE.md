# `webapp/` — 실습 웹앱

교재 `pandas.md` 의 짝. 글로 전달되지 않는 것을 **실행으로** 보여 준다.
장 번호와 색 배정을 교재와 일치시킨다(교재 7장 = 웹앱 7장).

## 구조

```
webapp/
  API.md          ★ 모듈 작성 계약. 화면 모듈을 쓰기 전에 반드시 읽는다
  build.js        원본 → src/core/data.js 생성 + 단일 파일 인라이너
  src/
    theme.css  app.css
    core/
      df.js       미니 DataFrame 엔진 (메인이 직접 작성)
      ui.js       공용 위젯
      app.js      셸 — 챕터 등록소·라우터·진도·테마
      data.js     실습 데이터 (빌드 생성. 손으로 고치지 않는다)
    modules/
      chNN-*.js   장별 화면. 파일명 사전순 = 표시 순서
  test/
```

## 절대 규칙 (전부 NumPy Lab 에서 실제로 깨져 본 것)

1. **로드 순서: `df → ui → data → app → modules → boot`.**
   `app.js` 가 `window.Lab` 을 정의하고 모듈이 로드 시점에 `Lab.register(...)` 를 부른다.
   순서가 뒤바뀌면 모듈이 **조용히 `Lab is not defined` 로 죽어** 장이 하나도 등록되지 않는다.
   문법 검사도 node 하네스도 통과한다. **브라우저로 열어 보지 않으면 절대 발견하지 못한다.**
2. **ES 모듈 문법(`import`/`export`) 금지.** 단일 파일 배포본에 인라인되므로 깨진다.
   모든 소스는 `window.X` 에 붙는 IIFE.
3. **`render(root)` 는 여러 번 호출된다.** 장을 다시 방문하면 다시 불린다.
   모듈 전역에 가변 상태를 두면 두 번째 방문에서 깨진다. `render` 안의 지역 변수 + `rebuild()` 패턴.
4. **화면의 숫자를 하드코딩하지 않는다.** `DF` 엔진으로 그 자리에서 계산한다.
   이것이 이 프로젝트의 존재 이유다.
5. **표 위젯의 HTML escape 는 열(`cols`) 속성이다.** `raw: true` 를 행에 붙이면 `<b>` 가 글자로 보인다.
6. **빌드는 원본이 없으면 기존 `data.js` 를 보존한다.** `buildData()` 가 `null` 을 반환하면
   "기존 파일 유지" 를 뜻한다. 그러지 않으면 저장소를 클론한 사람이 빌드하는 순간 데이터가 전부 날아간다.

## 데이터 정책

배포본은 **합성 데이터**를 쓴다(타이타닉·라멘·전복). `lab_earthquake.csv` 만 USGS 퍼블릭
도메인이라 실데이터다. **합성인 데이터는 화면에 합성이라고 밝힌다.**
교재 본문은 원본 파일명을 그대로 쓰므로(학생이 자기 파일로 따라할 수 있게), 합성 이야기는
웹앱 화면과 README 에서만 한다. 자세한 근거는 `../CLAUDE.md` §10·§11.

## 색 배정 (전 장 고정. 검증기로 확정한 값)

| 역할 | 라이트 | 다크 | CSS 변수 |
|:---|:---|:---|:---|
| **원본** | `#2a78d6` | `#3987e5` | `--c-original` |
| **사본** | `#eb6834` | `#d95926` | `--c-copy` |
| **결과** | `#1baf7a` | `#199e70` | `--c-result` |
| **강조** | 색 아님 — 2px 링 + 굵은 라벨 | | `--c-focus-ring` |
| **에러/경고** | `#d03b3b` | `#d03b3b` | `--c-danger` |
| **결측(NaN)** | `#898781` + 45° 해칭 | 같음 | `--c-na`, `url(#na-hatch)` |

학생이 색으로 역할을 익히므로 **절대 바꾸지 않는다.**
**강조는 노랑이 아니다** — 노랑을 넣으면 주황과 구분되지 않아 검증기가 두 모드 모두 FAIL 을 냈다
(다크 CVD ΔE 4.8, 라이트 정상시야 ΔE 13.7). 근거는 `../CLAUDE.md` §7-1.

라이트 모드의 결과색은 표면 대비 2.74:1 이라 **숫자 라벨 또는 표 보기를 반드시 함께** 낸다.
계열이 4개 이상 필요하면 색을 추가하지 말고 "그 외" 로 접거나 차트를 나눈다.

차트를 만들기 전에 `dataviz` 스킬을 로드하고, 팔레트를 건드렸다면 `validate_palette.js` 를 다시 돌린다.
