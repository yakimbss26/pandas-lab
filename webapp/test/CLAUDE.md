# `webapp/test/` — 검증 4중 구조

교육 자료가 틀린 값을 가르치면 안 된다. 네 단계로 막는다.

| 단계 | 무엇을 | 파일 | 상태 |
|:--:|:---|:---|:---|
| 1 | 엔진 단위 테스트 | `df.test.js` | **164건 통과** |
| 2 | 엔진 ↔ 실제 pandas 교차 검증 | `gen_expected.py` → `expected.json` → `cross.test.js` | **88건 통과** |
| 3 | 교재 코드 블록 실행 + 출력 대조 | `verify_md.py`, `verify_outputs.py` | 미작성 |
| 4 | 브라우저 실조작 | `browser_check.js` | 7개 장 통과 |
| — | 배포 산출물 저작권·비밀 검사 | `check_licensing.js` | 통과 |

**2번이 가장 강한 보증이다.** 손계산 기대값에는 사람의 착각이 섞이지만 실제 pandas 가 낸 출력은 그렇지 않다.

### 2번이 실제로 잡아낸 엔진 결함 (단위 테스트가 놓친 것)

교차 검증을 붙이자마자 두 개가 나왔다. 둘 다 "그럴듯해서" 손계산 테스트로는 안 잡혔다.

1. **정렬 후 dtype 이 float64 로 올라가지 않았다.**
   `s.add(other, fill_value=0)` 에서 한쪽에 없는 라벨이 있으면 pandas 는 결과를 `float64` 로 만든다.
   `fill_value` 로 채워서 결과가 전부 정수여도 그렇다 — 중간에 NaN 이 생기기 때문이다.
   엔진은 값에서 dtype 을 다시 추론해 `int64` 를 냈다.
2. **`value_counts(dropna=False)` 가 NaN 을 맨 뒤에 붙였다.**
   pandas 는 NaN 을 다른 값과 똑같이 개수 내림차순으로 놓고, 개수가 같으면 **처음 나온 순서**로 정렬한다.
   `['S','C',NaN,'S','Q','S']` → `S, C, NaN, Q` 로 **Q 가 NaN 뒤에 온다.**

교훈: **엔진의 "그럴듯한" 동작은 손계산 테스트로 안 잡힌다.** 실제 라이브러리와 대조해야 한다.

### 3번째 결함은 화면 모듈을 만들다 나왔다 (교차 검증도 놓쳤다)

**`s.isna().sum()` 이 0 을 반환했다.** 교재 8장이 가르치는 가장 흔한 관용구인데 조용히 틀렸다.
원인: `Series._nums()` 가 `typeof v === 'number'` 만 인정해 **불린을 세지 않았다.**
pandas 는 `True` 를 1 로 센다(`pd.Series([True,False,True]).sum()` → 2).

교차 검증이 놓친 이유: `frame_isna_sum`(DataFrame 수준)만 케이스에 있었고,
`DataFrame.sum()` 은 불린을 특별 처리하고 있어서 통과했다. **Series 수준 경로가 비어 있었다.**

교훈: **같은 개념의 두 경로(Series / DataFrame)를 둘 다 케이스에 넣어라.**
한쪽만 검증하면 비대칭이 남는다. 지금은 `series_isna_sum`, `series_notna_sum`,
`s_bool-sum/mean/count` 케이스가 추가되어 있다.

그리고 **화면을 만들어 보는 것 자체가 검증**이다. 실제로 쓰이는 경로가 드러난다.

### 그리고 검증 하네스 자체가 먼저 틀렸다

첫 실행에서 12건이 실패했는데 그중 10건은 pandas 도 엔진도 아니라 **`gen_expected.py` 의 버그**였다.
`jsonable()` 이 파이썬 기본 `int` 를 처리하지 않아 인덱스 라벨이 `"0"` 같은 **문자열로** 나갔다.
`[EXCEPTION]` 이나 대량 불일치를 보면 **라이브러리보다 하네스를 먼저 의심하라.**
(`bool` 은 `int` 의 하위 타입이므로 `bool` 을 먼저 검사해야 한다.)

## 오탐 판별 기준 (미리 정해 둔다)

NumPy Lab 에서 `verify_outputs.py` 가 보고한 "값 불일치" 20건 중 **19건이 오탐**이었다.
같은 실수를 반복하지 않으려면 판별 기준이 필요하다.

### 오탐으로 처리할 것

1. **출력 뒤에 붙은 설명 주석을 기대 출력으로 묶은 경우.**
   교재는 `# (891, 12)` 처럼 출력을 주석으로 적는다. 주석 뒤에 설명이 이어지면 분리해야 한다.
2. **교재가 버전별 값을 나란히 적어 둔 곳.** "원본은 `object`, 지금은 `str`" 같은 대비 서술.
3. **`# ⚠` 블록의 출력.** 의도적으로 "틀린" 결과를 실은 것이다. 에러가 아니라 정상 실행이다.
4. **표 정렬 공백 차이.** pandas 의 `to_string` 폭은 터미널 폭 설정에 따라 달라진다.
   값이 같으면 통과로 본다.

### 진짜 오류로 처리할 것

1. 숫자 값 자체가 다른 경우 (자리수·부호·크기)
2. dtype 이 다른 경우
3. 결측 개수가 다른 경우
4. `# ✗` 를 붙였는데 에러도 경고도 나지 않는 경우 (또는 그 반대)

## ★ 이 프로젝트에서 미리 알고 있는 오탐 요인

**pandas 3.0 의 `ChainedAssignmentError` 는 이름과 달리 예외가 아니라 경고다.**
코드는 끝까지 돌고 결과만 반영되지 않는다.

- `try/except` 로는 잡히지 않는다. `warnings.catch_warnings(record=True)` +
  `warnings.simplefilter('always')` 로 캡처해야 한다.
- 검증 스크립트가 "경고 없음 = 정상" 으로 판정하면 **교재가 가르치는 가장 중요한 함정을 놓친다.**
- `# ✗` 블록 중 이 경고만 내는 것들이 있으므로, `verify_md.py` 는
  **예외 또는 경고 중 하나라도 있으면 통과**로 판정해야 한다.

## 4단계 — 브라우저 실검증

앱을 띄우고(`npm start`) 콘솔이나 브라우저 도구에서 한 줄:

```js
fetch('/webapp/test/browser_check.js').then(r => r.text()).then(eval)
```

검사하는 것: 전역 4개(`DF`/`UI`/`Lab`/`LabData`) · 장 등록 수와 번호 중복 ·
`render` 두 번 호출 후 노드 수 동일(재방문 오염) · 모든 버튼·슬라이더 조작 ·
표 셀의 태그 누출 · 차트마다 표 보기 twin · 테마 토큰 · `scrollRestoration`.

### ★ 클릭은 반드시 살아 있는 DOM 에서 다시 찾아라

처음 이 검사를 만들 때 `KeyError` 6건이 나왔는데 **전부 오탐**이었다.
버튼 목록을 한 번 담아 두고 순회 클릭했는데, 그 사이 모드 전환으로 버튼이 교체되어
**DOM 에서 떨어진 노드**를 누른 것이었다. 떨어진 노드도 핸들러는 옛 클로저로 실행되므로
실제 사용에서는 불가능한 에러가 난다. `browser_check.js` 는 매 반복마다 목록을 다시 만든다.

### 실제로 잡은 버그

**앱을 열면 장 제목을 지나친 자리에서 시작했다.** 원인이 둘 겹쳐 있었다.
`render()` 가 매번 `main.scrollIntoView()` 를 부른 것(sticky 헤더 높이를 고려하지 않는다),
그리고 브라우저의 스크롤 복원. 해시로 장을 옮기는 앱이므로 `history.scrollRestoration = 'manual'`
로 끄고, 스크롤은 **장을 옮길 때만** 하도록 고쳤다. node 하네스로는 절대 잡히지 않는 종류다.

## 흔히 깨지는 곳

- **`std` 의 `ddof`.** pandas 기본은 `ddof=1`, numpy 는 `ddof=0`. 엔진은 `ddof=1` 로 맞췄다.
  교차 검증에서 이걸 틀리면 모든 `std` 가 불일치로 뜬다.
- **JS 는 `1` 과 `1.0` 을 구분하지 못한다.** `gen_expected.py` 가 float 컬럼을 넘길 때
  dtype 을 함께 실어야 엔진이 `int64` 로 되돌아가지 않는다.
- **교재 검증이 파일을 만든다.** `to_pickle`/`to_csv` 예제가 실제로 파일을 쓴다.
  스크래치패드에 쓰게 하고 `.gitignore` 에 넣어라.
- **matplotlib 이 창을 띄우며 멈춘다.** `MPLBACKEND=Agg` 를 설정한다.
- **seaborn 이 없다.** 원본의 `sns.distplot` 계열은 재현 불가다. 교재도 matplotlib 만 쓴다.
