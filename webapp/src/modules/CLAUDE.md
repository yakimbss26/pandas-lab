# `webapp/src/modules/` — 장별 화면

파일 하나 = 장 하나. **파일명 사전순이 표시 순서다**(`build.js` 가 `readdirSync().sort()` 한다).
그래서 `ch01-`, `ch02-` … 처럼 두 자리 번호를 쓴다. `ch1-` 로 쓰면 `ch10-` 뒤로 밀린다.

`quest.js` 는 장이 아니다 — **스스로 하기(과제) 화면**이고 `extra: true` 로 등록한다.
`ch` 로 시작하지 않으므로 사전순에서 장들 뒤로 가고, 진도 분모(14장)에도 들어가지 않는다.
자세한 것은 아래 "과제 화면" 절.

## 쓰기 전에

**`../../API.md` 를 끝까지 읽어라.** 여기 있는 것만 쓴다. 자기 표·차트를 새로 만들면
장마다 모양이 달라지고, 병렬로 쓴 화면들이 하나의 앱으로 보이지 않는다.

## 골격

```js
(function () {
  'use strict';
  Lab.register({
    id: 'ch07-copy',        // 파일명과 같게. URL 해시가 된다
    num: 7,                 // 교재 장 번호와 반드시 일치
    title: '뷰와 복사, Copy-on-Write',
    subtitle: '한 줄 요약. 장 머리와 홈 타일에 함께 쓴다',
    sim: '슬라이스 vs 마스크 · 쓰는 순간 복사 · 연쇄 할당 함정 3종',
    key: true,              // ★ 가장 많이 틀리는 개념 (5·6·7장만)

    render: function (root) { /* … */ }
  });
})();
```

`sim` 은 **홈 화면 타일과 홈의 시뮬레이터 표**에 그대로 나간다. 장 안의 `.panel-title` 을 줄여
`·` 로 잇는다. 시뮬레이터를 더하거나 빼면 여기도 고친다 — **없는 것을 광고하면 학생이 찾다가 지친다.**

## 이 폴더에서 흔히 깨지는 곳

1. **ES 모듈 문법 금지.** `import`/`export` 를 쓰면 단일 파일 배포본에서 깨진다. IIFE 로 감싼다.
2. **`render(root)` 는 여러 번 호출된다.** 장을 다시 방문하면 다시 불린다.
   모듈 전역에 가변 상태를 두면 두 번째 방문에서 깨진다.
   `render` 안의 지역 변수 + `rebuild()` 패턴을 쓴다(API.md §1 ②).
3. **`root` 밖에 무언가를 붙이지 마라.** 셸은 `root` 만 비운다. `document.body` 에 붙인 것은 남는다.
   (예외: `UI` 의 툴팁 레이어. 그건 `UI` 가 관리한다.)
4. **숫자를 하드코딩하지 마라.** `DF` 로 그 자리에서 계산한다. 이게 이 프로젝트의 존재 이유다.
5. **`UI.table` 의 `raw` 는 열 속성이다.** 행에 붙이면 `<b>` 가 글자로 보인다.
6. **노랑을 쓰지 마라.** 주황과 구분되지 않아 색약 검증에서 FAIL 이 난다. 강조는 링(`is-focus`)이다.
7. **`DF.trace.enable()` 은 로그를 비운다.** 쓰고 나면 `disable()` 해서 다른 장에 새지 않게 한다.
8. **`node --check` 를 통과해도 브라우저에서 죽을 수 있다.** 없는 API 호출, `register` 오타는
   문법 검사로 안 잡힌다. Phase 4 의 브라우저 실검증에서 잡힌다.
9. **확인 문제는 뒤에 더한다.** 진도는 `render` 안에서 만들어진 순서로 번호가 붙는다
   (`ch07-copy:q0`, `q1`, …). 중간에 끼워 넣으면 뒤 번호가 밀려 학생이 맞힌 기록이 다른 문제로 옮겨 간다.
10. **새 셸 클래스나 새 색 토큰을 만들지 마라.** 이 앱은 NumPy Lab 과 한 벌이다.
   쓸 수 있는 클래스 목록은 `../../CLAUDE.md` 의 "디자인 통일" 절에 있다.

## ★ 원본 데이터의 값을 코드에 적지 마라 (두 번 걸렸다)

모듈은 단일 파일 배포본(`pandas-lab.html`)에 인라인되어 **공개된다.** 그래서
`webapp/test/check_licensing.js` 가 원본 데이터의 특징적인 값을 금지어로 잡는다.

실제로 두 번 걸렸다.

| 어디 | 무엇 | 왜 문제인가 |
|:---|:---|:---|
| `ch01-why.js` | 실존 운동선수 이름을 예제 데이터로 | 실존 인물의 나이·키를 사실처럼 싣게 된다 |
| `ch10-agg.js` | 퀴즈 해설 문자열에 타이타닉 승객 이름 | 원본 데이터의 값을 배포본에 넣는 것이다 |

**규칙**

- 예제 이름은 **중립적으로** 만든다: 김민준 · 이서연 · 박도윤 · 최하은 · 정우진 · 한소율
- 원본 데이터의 값이 필요하면 **문자열로 적지 말고 그 자리에서 읽어라**:
  `LabData.frame('titanic').col('Name').at(0)` — 합성 데이터의 값이 나온다
- 설명·퀴즈 해설에서도 마찬가지다. "사람 이름 같은 문자열" 처럼 **일반화해서** 쓴다
- 실존 인물·구단·학교의 실제 이름을 쓰지 않는다

보고 전에 반드시:

```bash
node webapp/test/check_licensing.js
```

## 과제 화면 (`quest.js`)

형식은 NumPy Lab 의 과제 화면에서 가져왔고 **내용은 pandas 로 새로 썼다.**
5단계 · 문항 25개 · 예측 5개 · 메모 8개 · 배지 5개.

핵심은 **예측 → 확인 → 뒤집기**다. 시작부에서 예측 다섯 개를 먼저 받고, 나중에 그 문항을
맞히면 "처음에는 X 라고 생각했다" 를 보여 주며, 확인서가 뒤집은 문항을 모은다.

### 여기서 실제로 넘어진 곳

1. **예측은 실재하는 문항 번호에 걸어야 한다.** 원본 노트북은 `"예측4"` 처럼 없는 번호를
   써서 "생각이 바뀐 문항" 집계에서 **조용히 빠졌다.** 지금은 다섯 개 모두 실재하는
   문항(`2-1a` `3-1` `4-1a` `5-2` `5-5`)에 걸려 있다. 문항을 지울 때 예측 대상인지 확인하라.
2. **문항을 빼면 예전 진도 키가 남아 분모가 어긋난다.** 화면은 25 라는데 사이드바 점은 26 을
   세면 점이 영원히 초록이 안 된다. `seed()` 가 **모르는 번호의 키를 지워** 스스로 고친다.
   문항을 빼거나 번호를 바꿀 때 이 정리가 도는지 확인하라(실제로 한 번 걸렸다).
3. **모달은 `close` 이벤트만 믿으면 안 된다.** 비동기라 노드가 DOM 에 남아 다음 창을 가린다.
   `UI.modal` 이 열 때 남은 창을 지우고 닫을 때도 직접 `remove` 한다.
4. **`window.open` 이 `null` 을 돌려주면서 현재 탭을 그냥 이동시키는 환경이 있다**
   (팝업 차단·키오스크). 그래서 장을 열기 **전에** 스크롤 위치를 `quest:return` 에 적어 두고,
   장 화면 맨 위에 "과제로 돌아가기" 줄을 띄운다. 돌아가면 그 자리로 복원된다.
   과제를 거치지 않고 장에 들어오면 그 줄은 뜨지 않는다.
5. **`.q-stem` 의 `Q1.` 카운터를 꺼야 한다.** 문항에 자체 번호(`2-1a`)가 있어서 겹친다.
   과제 루트에 `.quest` 클래스를 붙이면 `content: none` 이 걸린다.
6. **짧은 답을 서술형으로 바꾸지 마라.** 표의 값 칸처럼 한 단어로 끝나는 것을 서술형으로
   물으면 어색하고 판정도 못 한다. 서술형은 "왜 그런가" 를 묻는 메모로만 쓴다.

### 답은 반드시 실행해서 넣는다

문항의 정답은 **실제 pandas 3.0.5 로 돌려 확인한 값**이다. 손계산으로 적지 마라.
확인 스크립트는 스크래치패드의 `probe_quest.py` 형식을 따른다 — 항목마다 **격리된 전역**에서
돌리고 **경고까지 캡처**한다(`ChainedAssignmentError` 는 예외가 아니라 경고라서,
"에러 없음 = 정상" 으로 판정하면 통째로 놓친다).

### 공용 PC

실습실에서 한 컴퓨터를 여러 학생이 쓴다. 시작할 때 이름을 받고 기록을 이름별로 나눈다.
"사람 바꾸기" 는 앞 사람 기록을 `questbox:<이름>` 으로 **보관한다 — 지우지 않는다.**
그 이름을 다시 넣으면 하던 데서 이어진다. 비밀번호는 없다(점수용 과제가 아니다).

  합쳐지기 전이면 `../../../docs/draft/part*.md`)
