## A. 사실·설명 오류 — 개념을 잘못 가르치는 것

### A-1. "기간: 1907년 1월 1일 - 2024년 12월 31일" — 서울 파일은 **10월 1일부터** `[실행확인]`

`8_데이터_시각화(2)` 셀 5 의 다운로드 안내. 실제 `seoul_temp_day.csv` 는 **1907-10-01** 에 시작한다
(부산 파일은 1907-01-01 부터가 맞다). 1907년은 92일뿐이라 연평균을 내면 5.10℃ 로 낮게 나온다(D-6).

**교재 서술**: 기간은 `df['날짜'].min()`, `.max()` 로 **직접 확인**하게 한다. 다운로드 안내를 믿지 않는다.

### A-2. "히스토그램은 주로 범주형 데이터 시각화에 효과적" — **반대다**

`8_데이터_시각화(2)` 셀 39 의 histplot 설명. 히스토그램은 **수치형 값을 구간으로 나눠** 개수를 센다.
범주형의 개수를 세는 것은 `countplot` 이다. 이 혼동이 D-2(연속값에 countplot → 막대 489개)로 이어진다.

**교재 서술**: "구간을 나눠야 하면 히스토그램, 값이 이미 몇 가지로 나뉘어 있으면 countplot" 으로 가른다.

### A-3. `plt.figure(3, figsize=(15, 5))` 의 3 은 "하위 그래프 개수" 가 아니다 `[실행확인]`

PDF (2) 의 설명: "plt.figure(하위 그래프 개수, figsize = (가로, 세로))".
첫 인자는 **그림 번호(num)** 다. 실행하면 그림 번호 3 인 빈 그림이 하나 생기고 축은 0개다.
하위 그래프는 뒤의 `plt.subplot(1, 3, k)` 가 만든다.

**교재 서술**: `fig, axes = plt.subplots(1, 3, figsize=(15, 5))` 로 그림과 축을 **한 번에** 만드는 쪽을 쓴다.

### A-4. PDF (2) 인구 배열의 오탈자 두 개 `[실행확인]`

시·도 인구 산점도 예제의 넘파이 배열:

| 항목 | PDF 값 | 실제 |
|:---|:---|:---|
| 대구 인구 | `393626` | **2,393,626** (`korea_pop.csv`) — 앞자리 2 가 빠졌다 |
| 인천 위도 | `35.45619` | 약 **37.456** — 부산(35.18)과 비슷한 자리에 찍힌다 |

그래프로 그리면 **대구가 제주보다 작은 원**(실제 크기의 약 6분의 1)으로, **인천이 경상도 해안**에 찍힌다. 에러는 없다.
**교재 서술**: 숫자를 손으로 옮겨 적지 않고 CSV 에서 읽는다. "그림이 이상하면 데이터를 의심하라" 의 예로 쓴다.

### A-5. "barplot 의 ci 옵션은 95% 신뢰구간…" — 지금은 `errorbar` 다 `[실행확인]`

설명 자체(막대 = 평균, 검은 선 = 95% 신뢰구간)는 맞다. 실행하면 막대 높이가 정확히 평균이다
(`a` 그룹 1, 2, 6 → 높이 3.0). 다만 매개변수 이름이 바뀌었다(C-5). 그리고 **이 신뢰구간은 부트스트랩으로
구하므로 실행할 때마다 조금씩 다르다** — 원본은 이 점을 말하지 않는다.

**교재 서술**: "막대 하나 뒤에 행이 몇 개 있는가" 를 먼저 보게 한다. 막대는 평균 **하나**만 보여 준다.

## B. 뷰·복사 함정 — 1부 7장과 이어지는 것

### B-1. `df['평균기온'].fillna(0, inplace=True)` — **아무 일도 일어나지 않는다** `[실행확인]`

`8_데이터_시각화(2)` 셀 12 가 결측 처리 방법으로 제시한 코드.

```
결측 전 757 -> 후 757
[경고] ChainedAssignmentError: A value is being set on a copy of a DataFrame or Series
       through chained assignment using an inplace method. Such inplace method never works ...
```

`df['평균기온']` 로 꺼낸 **임시 조각**을 제자리에서 고쳤고 그 조각은 버려진다. 1부 7장의 연쇄 할당 그대로다.
**예외가 아니라 경고**라서 노트북은 끝까지 돌고, 그 뒤 모든 그래프가 결측이 남은 채로 그려진다.

**교재 서술**: `df['평균기온'] = df['평균기온'].fillna(0)` — **대입**으로 쓴다. 7장을 가리킨다.

## C. 버전 차이 — 원본 시절에는 됐던 것

### C-1. `fillna(method='bfill')` → **TypeError** `[실행확인]`

```
TypeError: NDFrame.fillna() got an unexpected keyword argument 'method'
```

`8_데이터_시각화(2)` 셀 14. 대체는 `df.bfill()` / `df.ffill()`.
**주의**: 서울 파일은 `bfill()` 을 해도 결측이 **4개 남는다** — 맨 끝 빈 행(D-7)은 뒤에 채울 값이 없기 때문이다.

### C-2. `temp_df.corr()` — 문자열 열이 있으면 **ValueError** `[실행확인]`

```
ValueError: could not convert string to float: '1907-10-01'
```

원본 셀 49 도 이 에러를 겪고 셀 51 에서 `numeric_only=True` 로 고쳤다. 교재는 이 순서를 그대로 살린다.
**하나 더**: `지점` 열(값이 108 하나뿐)을 남겨 두면 그 행과 열이 **전부 NaN** 이다 — 값이 변하지 않는 열은
상관계수를 정의할 수 없다. 히트맵에 빈 줄이 생긴다.

### C-3. `sns.distplot` — **아직 있다.** 경고가 뜰 뿐이다 `[실행확인]`

```
distplot 존재: True
[경고] UserWarning: `distplot` is a deprecated function and will be removed in seaborn v0.14.0.
```

**"없어졌다" 고 쓰지 않는다.** "0.14 에서 없어질 예정이라 경고가 뜬다" 가 사실이다.
대체: 막대로 보려면 `histplot`, 곡선으로 보려면 `kdeplot`, 둘 다 `histplot(..., kde=True)`.

같은 경고. 대체는 `g.map(sns.kdeplot, '평균기온')` 과 `g.map(sns.rugplot, '평균기온')` 을 두 번.

`8_데이터_시각화(2)` 셀 22. 색이 **아무 정보도 싣지 않는데** 막대마다 다른 색을 칠한 것이기도 하다.
**교재 서술**: 한 색으로 칠한다. 색은 `hue` 로 **뜻이 있을 때만** 나눈다(V5 장).

## D. 조용한 오류 — 에러도 경고도 없는데 결과가 틀리는 것 (`# ⚠` 후보)

### D-1. `plt.figure(figsize=(20, 3))` 다음 `plt.figure(dpi=300)` — **그림이 두 장** `[실행확인]`

`8_데이터_시각화(2)` 셀 20, 42.

```
열린 그림 수: 2
그림별 크기(인치): [(20.0, 3.0), (6.4, 4.8)]
그림별 선 개수: [0, 1]
```

`plt.figure()` 는 부를 때마다 **새 그림**을 만든다. 크기를 준 첫 그림은 **빈 채로** 남고, 선은 기본 크기의
두 번째 그림에 그려진다. 주피터에서는 빈 네모 하나와 작은 그래프 하나가 나온다.
**교재 서술**: `plt.figure(figsize=(20, 3), dpi=300)` — 옵션은 **한 번에** 준다.

### D-2. 연속값에 `countplot` — **막대 489개** `[실행확인]`

`8_데이터_시각화(2)` 셀 26 `sns.countplot(data=temp_df, x='평균기온')`.
평균기온 고유값이 489개라 막대가 489개, x축 글자는 겹쳐서 읽을 수 없다. A-2 의 결과다.
**교재 서술**: 같은 질문("어느 기온이 흔한가")에는 `histplot(bins=...)` 을 쓴다. `bins` 를 바꾸며 모양이 어떻게
변하는지 보게 한다(웹앱 V4).

### D-3. `temp_df['년'] > '2010'` — **문자열 비교가 우연히 맞는다** `[실행확인]`

`str.split` 으로 뽑은 `년` 은 **문자열**이다. 네 자리 연도끼리는 사전순 = 크기순이라 결과가 맞아 보인다
(2011~2024, 5114행). 그러나

```
'999' > '2010'   ->  True
'10000' > '2010' ->  False
```

그리고 원본은 셀 53 에서 `년` 을 숫자로 바꾼다. **그 뒤에 셀 22 를 다시 돌리면**

```
TypeError: Invalid comparison between dtype=int64 and str
```

실행 순서에 따라 되기도 하고 안 되기도 하는 코드 — 1부 13장(노트북이 거짓말할 때)의 사례 그대로다.
**교재 서술**: 날짜는 처음부터 `pd.to_datetime` 으로 바꾸고 `.dt.year` 로 **숫자** 연도를 얻는다(V1 장).

### D-4. 숫자 `hue='월'` — 범례에 **2, 4, 6, 8, 10, 12 만** 나온다 `[실행확인]`

월을 숫자로 바꾼 뒤 `sns.scatterplot(..., hue='월')` 을 하면 seaborn 이 **연속값**으로 보고 색 띠를 쓴다.
범례 항목: `['2', '4', '6', '8', '10', '12']` — 홀수 달이 범례에서 사라진다(점은 그려진다).
**교재 서술**: 범주로 쓰려면 `hue=df['월'].astype(str)` 또는 `palette` 를 범주형으로. 이게 dtype 이 그림을 바꾸는 예다.

### D-5. PDF (2) 산점도의 `s` 에 **음수**가 섞임 — 점 47개가 사라진다 `[실행확인]`

`size = np.random.randint(-200, 200, 100)` 을 점 크기로 썼다. 음수 47개는

```
[경고] RuntimeWarning: invalid value encountered in sqrt
```

만 남기고 **그려지지 않는다.** 경고는 넘파이에서 나와 원인을 짐작하기 어렵다.

### D-6. ★ "서울에서 가장 추운 해는 1953년" — **결측이 만든 착시** `[실행확인]`

연도별 `mean()` 을 그대로 내면 가장 추운 해가 **1953년 0.64℃** 다. 그런데 1953년은 평균기온 값이
**12월 한 달(31일)** 에만 있다. 겨울 한 달의 평균을 연평균이라고 부른 것이다.
유효일 360일 이상인 해만 보면 가장 추운 해는 **1947년 9.66℃** 다(수치는 정답표 §1).

`mean()` 은 NaN 을 건너뛰므로 **에러도 경고도 없다.** 1부 8장의 "결측은 조용하다" 가 그래프에서 터지는 순간이다.
**교재 서술**: 연도별로 묶을 때 `count()` 를 **함께** 내서 몇 날로 만든 평균인지 보여 준다. V5·V6 의 중심 사례.

### D-7. 서울 파일의 **빈 마지막 행** — `지점` 이 float64 가 된다 `[실행확인]`

마지막 행(42396)의 날짜는 탭 하나, 나머지는 NaN. 그래서
- `지점` 이 `108` 이 아니라 `108.0` (float64) 으로 읽힌다 — "ID 열이 왜 실수지?"
- `bfill()` 로 결측을 채워도 4개가 남는다(C-1)
- `str.replace('\t', '')` 만 하면 날짜가 **빈 문자열**인 행이 남아 `pd.to_datetime` 이 NaT 를 만든다
- **아무것도 안 하고 `pd.to_datetime(df['날짜'])` 를 하면 `ValueError` 로 멈춘다** `[실행확인]`

```
원본 그대로                  -> ValueError: time data "\t" doesn't match format "\t%Y-%m-%d"
빈 행만 뺀 것(탭은 그대로)    -> datetime64[us], NaT 0
replace 로 탭만 지운 것       -> datetime64[us], NaT 1 (빈 행이 NaT 가 된다)
```

pandas 는 **첫 값에서 형식을 추정**해(`"\t%Y-%m-%d"` — 탭까지 형식에 넣는다) 나머지에 엄격하게 적용한다.
그래서 탭이 붙은 날짜 4만 개는 다 읽지만, 탭 **하나뿐인** 마지막 행에서 멈춘다. 에러 문구에 탭이 보이지 않아
원인을 찾기 어렵다. 날짜 dtype 은 `datetime64[ns]` 가 아니라 **`datetime64[us]`** 다(pandas 3.0).

**교재 서술**: 읽자마자 `tail()` 을 본다. 원본도 `tail()` 을 부르지만 이 행을 짚지 않고 넘어간다.
그리고 **빈 행을 먼저 걸러야 `to_datetime` 이 된다** 는 순서를 실패로 한 번 보여 준다(`# ✗`).

### D-8. `read_csv` 에 `thousands=','` 를 빼면 — 숫자 309열이 **전부 문자열** `[실행확인]`

`korea_pop.csv` 는 `"51,669,716"` 처럼 쉼표가 박혀 있다. 빼고 읽으면 dtype `{'str': 309, 'int64': 1}`.
이 상태로 `plt.barh` 에 넣으면 막대 길이가 아니라 **문자열 범주**로 그려진다.
PDF (5) 는 옵션을 바르게 썼다. 교재는 **빼면 어떻게 되는지** 를 함께 보여 준다.

### D-9. PDF (5) `df.iloc[0, 106:207]` — **맞지만 부서지기 쉽다** `[실행확인]`

열 106 = `2021년08월_남_0세`, 열 206 = `2021년08월_남_100세 이상`, 열 209 = `여_0세`. 위치가 **정확히 맞다.**
그러나 다음 달 파일에 열이 하나만 늘어도 조용히 다른 열을 집는다.
`filter(regex=r'_남_\d+세|_남_100세 이상')` 로 **이름으로** 고르면 같은 101개가 나온다. 제주 남−여 합계 2041명,
남이 가장 많이 앞서는 55세(+666), 여가 가장 많이 앞서는 88세(+861) — PDF 의 결과와 일치한다.
**교재 서술**: 정정이 아니라 **개선**으로 싣는다. 1부 5장(loc/iloc)과 V2(넓은 표) 를 잇는 예.
