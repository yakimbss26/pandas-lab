# 집필 규칙 — `pandas.md` 를 쓰는 모든 에이전트가 따른다

대상은 **과학고 1학년**이다. 파이썬 기본 문법과 넘파이는 한 번 배웠다고 가정하고,
pandas 는 처음이라고 가정한다. 언어는 **한국어**.

---

## 1. 절대 규칙

1. **수치를 손으로 적지 않는다.** shape, 평균, 결측 개수, 고유값 수 등 모든 값은
   [정답표.md](정답표.md) 에서 가져온다. 표에 없는 값이 필요하면 **직접 실행해서** 얻고,
   어떻게 얻었는지 각주로 남긴다. 기억이나 추측으로 쓴 숫자는 전부 틀린 것으로 취급한다.
2. **원본 노트북의 출력을 복사하지 않는다.** 원본은 pandas 1.1.5 / 1.3.4 기준이라 지금과 다르다.
   대표적으로 `dtype: object` → `str`, `Name: Pclass` → `Name: count`,
   `memory usage: 141.2+ KB` → `141.2 KB`.
3. **코드 블록은 실제로 돌아가야 한다.** `verify_md.py` 가 전부 실행한다.
   실행 환경은 pandas 3.0.5 / python 3.13. 파이썬 인터프리터는
   `C:\Users\user\AppData\Local\Programs\Python\Python313\python.exe` (다른 `python` 은 스텁).
4. **[정정표.md](정정표.md) 를 먼저 읽는다.** 원본이 틀린 것을 그대로 옮기면 안 된다.
5. **에러 나는 코드를 실을 때는 반드시 표시한다.** 아래 §4 의 형식을 쓴다.

## 2. 문체

- **평서문. 단정적으로.** "~할 수 있습니다" 보다 "~한다". 존댓말을 쓰지 않는다.
- **왜 그런가를 먼저, 어떻게 하는가를 나중에.** API 목록이 아니라 설명이다.
- 한 문단은 한 가지만 말한다. 세 줄을 넘기면 나눈다.
- **비유는 하나만 쓰고 끝까지 유지한다.** 같은 개념에 비유를 두 개 붙이지 않는다.
- 학생을 "여러분" 이라고 부르지 않는다. 필요하면 "우리".
- 겁주지 않는다. "주의!", "반드시 기억하세요!" 같은 감탄부호를 남발하지 않는다.
  위험한 것은 **왜 위험한지 보여주면** 학생이 알아서 조심한다.
- 영어 용어는 **처음 나올 때 한 번만** 괄호로 원어를 병기한다. 그 뒤로는 한국어로 통일.
  예: 결측값(missing value) → 이후 "결측값".
  단 `DataFrame`, `Series`, `dtype`, `groupby` 등 코드에 그대로 나오는 이름은 영어를 유지한다.

## 3. 장의 구조

각 장은 이 순서를 지킨다.

```markdown
## N장. 제목

> 한 문장 요약. 이 장을 읽으면 무엇을 할 수 있게 되는가.

### N.1 <문제 제기>

먼저 "이게 없으면 무엇이 불편한가" 를 보여준다. 코드로 실패를 한 번 보여주면 가장 좋다.

### N.2 ~ N.k <내용>

### N.k+1 흔한 실수

이 장에서 학생이 실제로 틀리는 것. 정정표에서 관련 항목을 가져온다.

### 확인 문제

2~4개. 답은 접어 둔다(§5).

### 🧪 실습실
> 웹앱 N장에서 <시뮬레이터 이름> 을 직접 조작해 보라.
```

**웹앱과 장 번호를 반드시 일치시킨다.** 교재 7장 = 웹앱 7장.

## 4. 코드 블록 형식

### 정상 코드 — 출력을 주석으로 붙인다

```python
import pandas as pd

t = pd.read_csv('train.csv')
t.shape
# (891, 12)
```

출력이 여러 줄이면 별도 블록으로 분리한다.

> **★ 출력 블록은 코드 블록 바로 뒤에 온다.** 사이에 설명 문장을 끼우면 `verify_md.py` 가
> 그 블록을 출력으로 인식하지 않는다(그게 맞는 동작이다 — "이 줄을 빼면 이런 경고가 뜬다"
> 같은 **예시** 블록을 출력으로 대조하면 안 되니까). 설명은 출력 블록 **뒤에** 쓴다.

```python
t['Pclass'].value_counts()
```

```text
Pclass
3    491
1    216
2    184
Name: count, dtype: int64
```

### 일부러 실패시키는 코드 — `# ✗` 로 표시

```python
# ✗ 이 코드는 아무 일도 하지 않는다
t['Sex'].replace({'male': 0}, inplace=True)
```

```python
# ✓ 이렇게 쓴다
t['Sex'] = t['Sex'].replace({'male': 0})
```

**`# ✗` 가 붙은 블록은 `verify_md.py` 가 "에러 또는 경고가 나야 정상" 으로 판정한다.**
표시를 빠뜨리면 검증이 실패한다. 반대로 정상 코드에 `# ✗` 를 붙이면 그것도 실패한다.

### 조용히 틀리는 코드 — `# ⚠` (가장 중요한 케이스)

에러도 경고도 없이 **그냥 의도와 다른 결과를 내는** 코드가 있다. 학생이 출력만 보고 성공했다고
믿는 지점이고, 그래서 교재가 반드시 다뤄야 한다. 이건 `# ✗` 가 아니라 `# ⚠` 를 붙인다.

```python
# ⚠ 에러도 경고도 없다. 그런데 첫 줄이 컬럼 이름이 되어 행이 하나 줄었다
d = pd.read_csv('housing.data', sep=r'\s+')
```

**세 가지 표시를 구분한다.**

| 표시 | 뜻 | `verify_md.py` 판정 |
|:--|:---|:---|
| (없음) | 정상 코드 | 에러·경고 없이 돌고 출력이 일치해야 한다 |
| `# ✗` | **에러나 경고가 난다** | 예외 또는 경고가 나야 정상 |
| `# ⚠` | **조용히 의도와 다른 결과** | 에러·경고 없이 돌아야 하고, 실린 출력과 일치해야 한다 |

`# ⚠` 블록에는 **무엇이 의도와 다른지 주석으로 반드시 적는다.** "이건 틀렸다" 만으로는 부족하다.

pandas 3.0 의 `ChainedAssignmentError` 는 이름과 달리 **예외가 아니라 경고**다. 코드는 끝까지
돌고 결과만 반영되지 않는다. 경고가 나므로 `# ✗` 를 쓰되, 주석에
**"경고만 뜨고 값은 그대로다"** 라고 명시한다. 예외로 멈춰 주는 것보다 위험한 케이스다.

## 5. 확인 문제 형식

```markdown
**문제 N-1.** 인덱스가 `[55, 56, 1, 2]` 인 DataFrame `temp` 에서
`temp.iloc[2]` 와 `temp.loc[2]` 는 각각 몇 번째 행을 가리키는가?

<details><summary>답</summary>

`iloc[2]` 는 위에서 세 번째 행(인덱스 라벨 `1`), `loc[2]` 는 라벨이 `2` 인 마지막 행이다.
`iloc` 는 위치를, `loc` 는 라벨을 본다.

</details>
```

답에는 **왜 그런지**까지 쓴다. 정답만 적으면 학생이 확인할 수 없다.

## 6. 표와 그림

- 표는 마크다운 표를 쓴다. 열이 6개를 넘으면 나눈다.
- **ASCII 다이어그램을 적극적으로 쓴다.** 특히 인덱스 정렬과 뷰/복사는 그림이 있어야 이해된다.

```text
s1:  a  b  c  d  e            결과:  a  NaN   (s2 에 없다)
     1  2  3  4  5                   b   8    2 + 6
                                     c  10    3 + 7
s2:  e  b  c  d  e  f                d  12    4 + 8
     5  6  7  8  9 10                e  10    5 + 5  ┐ s2 의 e 가 둘이라
                                     e  14    5 + 9  ┘ 두 줄이 된다
                                     f  NaN   (s1 에 없다)
```

- 이미지 파일을 만들지 않는다. 외부 이미지를 링크하지 않는다(원본 노트북이 걸어 둔
  `storage.googleapis.com`, `cdn-images-1.medium.com` 링크는 **가져오지 않는다**).

## 7. 색·역할 (웹앱과 맞춘다)

교재에서 색을 언급할 때는 웹앱 배정을 따른다.

**원본=파랑 · 사본=주황 · 결과=초록 · 에러/경고=빨강 · 결측(NaN)=회색 해칭**

**강조는 색이 아니다** — 테두리와 굵은 글씨로 표시한다(노랑을 쓰면 주황과 구분되지 않아
색약 검증을 통과하지 못한다). 자세한 근거는 `../CLAUDE.md` §7-1.
