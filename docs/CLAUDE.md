# `docs/` — Phase 0 산출물

`수업자료/` 를 읽고 **사실 확인까지 끝낸 결과**를 담는 폴더다.
교재 집필 에이전트와 화면 모듈 에이전트가 참조하는 단일 기준이며, 여기 없는 수치는 쓰지 않는다.

## 파일

| 파일 | 무엇인가 | 누가 쓰는가 |
|:---|:---|:---|
| `정답표.md` | 데이터 7개의 shape·dtype·결측·통계·범주 분포·head(5). **실제 pandas 3.0.5 로 계산** | 교재 집필, 화면 모듈, 검증 |
| `정답표.json` | 위와 같은 내용의 기계 판독용. `webapp/build.js` 와 `test/gen_expected.py` 가 읽는다 | 빌드, 교차 검증 |
| `정정표.md` | 원본에서 바로잡을 것. 사실 오류 / 뷰·복사 함정 / 버전 차이 / 단순 실수 / 살릴 것 | 교재 집필 (필수 선독) |
| `정정표-실행기록.md` | 정정표의 **근거**. 원본 코드를 그대로 실행한 원시 기록 (출력·경고·예외) | 정정표를 의심할 때 |
| `수업자료-인벤토리.md` | 파일 전수 목록, 성격, 저작권·자격증명 상태 | Phase 5 배포, 범위 결정 |

## 이 폴더의 규칙

1. **손으로 수치를 적지 않는다.** `정답표.md` 는 `scratchpad/make_facts.py` 가 생성한다.
   값을 고쳐야 하면 스크립트를 고쳐 다시 돌린다.
2. **"바뀌었다 / 없어졌다" 를 추측으로 쓰지 않는다.** `정정표.md` 의 `[실행확인]` 표시가 근거다.
   표시 없는 항목은 원본 독해로 찾은 것이며 교재 반영 전에 실행으로 확인한다.
3. **정답표는 pandas 버전에 묶여 있다.** 헤더에 `pandas 3.0.5` 가 적혀 있다.
   환경을 올리면 `make_facts.py` 를 다시 돌리고, 달라진 값이 있으면 교재도 함께 고친다.
4. 원본 노트북의 출력값을 교재에 복사하지 않는다. **원본은 pandas 1.1.5 / 1.3.4 기준이라 틀린다**
   (대표적으로 `dtype: object` → `str`, `Name: Pclass` → `Name: count`).

## 흔히 깨지는 곳

- `정답표.md` 의 `std` 는 **pandas 기본 `ddof=1`** 이다. numpy 의 `np.std` 기본값(`ddof=0`)과 다르다.
  둘 다 실어 두었으니 교재에서 어느 쪽을 쓰는지 명시할 것. 미니 엔진 `df.js` 도 `ddof=1` 로 맞춘다.
- `정답표.json` 의 카테고리 분포는 **상위 20개만** 담고 있다. 전체가 필요하면 스크립트를 고친다
  (조용히 잘린 값을 전체로 착각하면 화면이 거짓을 말한다).
- 인벤토리의 **자격증명 유출 항목(§5)은 배포 직전에 다시 확인**한다. 잊으면 공개 저장소에 키가 올라간다.
